## 📖 Proje Hakkında / About
**TR:** Restorant1, zengin menü seçenekleri, iştah açıcı görsel sunumları ve şık atmosferiyle misafirlerine en iyi deneyimi vaat eden restoranlar için geliştirilmiş modern ve kullanıcı dostu bir frontend web arayüzüdür.

**EN:** Restorant1 is a modern and user-friendly frontend web interface developed for restaurants promising their guests the best experience with rich menu options, appetizing visual presentations, and an elegant atmosphere.

---

## ✨ Özellikler / Key Features
- 📜 **Zengin Menü Vitrini / Rich Menu Showcase:** Başlangıçlar, ana yemekler, tatlılar ve içecekler için kategorize edilmiş şık alanlar. / Stylish categorized sections for starters, main courses, desserts, and beverages.
- 🎨 **Gurme Konsept Tasarımı / Gourmet Concept Design:** Yeme-içme sektörünün ruhuna uygun, göz alıcı ve iştah kabartan renk paleti. / Eye-catching and appetizing color palette fitting the spirit of the food and beverage industry.
- 📅 **Rezervasyon & İletişim / Reservation & Contact:** Müşterilerin masa ayırtması veya kolayca iletişime geçmesi için tasarlanmış form yapıları. / Form structures designed for customers to book tables or easily get in touch.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil, tablet ve masaüstü cihazlarda kusursuz görüntüleme performansı. / Flawless viewing performance across mobile, tablet, and desktop devices.

---

## 🛠️️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik yapı ve SEO uyumlu etiketler / Semantic structure and SEO-friendly tags
* **CSS3:** Özel stiller, Flexbox/Grid mizanpajları ve geçiş efektleri / Custom styles, Flexbox/Grid layouts, and transition effects
* **JavaScript:** Dinamik menü filtreleme ve etkileşimli arayüz özellikleri / Dynamic menu filtering and interactive interface features
